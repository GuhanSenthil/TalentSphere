# 🚀 TalentSphere

### AI-Powered Recruitment & Professional Networking Platform

TalentSphere is an intelligent hiring ecosystem that leverages **Large Language Models (LLMs)** to transform recruitment and job searching. It provides automated resume screening, AI-driven job matching, and a professional networking space—all in one platform.

---

## 🌟 Features

### 👤 For Candidates
- 🔍 Intelligent Job Matching using AI
- 📄 Resume Analyzer & ATS Optimizer
- 📊 Application Tracking Dashboard
- 🌐 Community Feed (Networking)
- 🖨️ Printable Resume Generator

### 🏢 For HR Professionals
- 📊 Smart Hiring Dashboard
- 🤖 AI Candidate Recommendations
- 📑 Application Management with AI Scoring
- 📌 Job Posting & Lifecycle Management

---

## 🧠 AI Capabilities
- Resume scoring with structured JSON output
- Skill gap detection & recommendations
- Contextual candidate-job matching
- Resume rewriting for ATS compatibility

---

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/TalentSphere.git
cd TalentSphere
````

### 2. Install Dependencies

```bash
npm install
```

### 3. Setup Environment Variables

Create a `.env` file in the root directory:

```env
VITE_GEMINI_API_KEY=your_api_key
VITE_FIREBASE_CONFIG=your_config
```

### 4. Run the App

```bash
npm run dev
```
